🔑 Código de recuperação do PIN
Se um cliente se esquecer do PIN, carrega em "Esqueci-me do PIN" na app e escreve este código. O PIN dele é apagado e pode criar outro. O código fica guardado de forma segura: nem a app o consegue ler.
Canais
Use ▲▼ para ordenar (⤒ põe no topo). Desmarque para esconder. Escreva um nome novo se quiser mudar o nome do canal. 🔒 = a app pede PIN para este canal.
Grupos
Use ▲▼ para ordenar. Desmarque o quadrado para esconder. Escreva um nome novo se quiser mudar o nome. 🔒 = a app pede PIN (cada cliente cria o seu PIN no aparelho).
